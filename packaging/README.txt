RO3 Asia แพตช์ภาษาไทย
====================

แพตช์คำอธิบายภาษาไทยแบบไม่เป็นทางการสำหรับ RO3 Asia เวอร์ชัน PC
แปลเฉพาะรายละเอียดสกิล เควส และไอเทม ส่วนชื่อ เมนู UI และค่าสถานะคงภาษาอังกฤษ

ติดตั้ง
1. ปิด RO3 และ RO3AsiaLauncher
2. เปิด Install-Thai.bat
3. เลือกโฟลเดอร์ Client ที่มี ro3.exe
4. เมื่อแสดง [OK] Thai patch installed ให้เปิดเกม

หากคำแปลยังไม่ขึ้นหลังติดตั้งครั้งแรก ให้ปิดเกม รัน Install-Thai.bat อีกครั้ง แล้วเปิดเกมใหม่

อัปเดต
- เปิด Update-Thai.bat เพื่อดาวน์โหลด Release ล่าสุด
- ใช้ Update-Thai.bat --local "C:\Games\RO3\Client" เมื่อต้องการใช้ไฟล์ในโฟลเดอร์นี้โดยไม่เชื่อมต่อ GitHub

กู้คืนหลังเกมซ่อมไฟล์
- เปิด Recover-Thai.bat หรือ Recover-After-Official-Repair.bat ตามสถานการณ์
- ระบบจะตรวจไฟล์สำรองและ SHA-256 ก่อนคืนค่า

ถอนการติดตั้ง
- ปิดเกมแล้วเปิด Uninstall-Thai.bat
- BepInEx ที่มีอยู่ก่อนติดตั้งแพตช์จะไม่ถูกลบโดยอัตโนมัติ

คำเตือน
แพตช์นี้ไม่เป็นทางการ ความเข้ากันได้กับอัปเดตเกม ระบบป้องกันโกง และข้อกำหนดการให้บริการไม่ได้รับการรับประกัน
