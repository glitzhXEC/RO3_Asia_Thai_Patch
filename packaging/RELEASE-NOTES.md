# RO3 Asia Thai Patch — Release Notes

- เพิ่ม RO3 Translation Editor แบบออฟไลน์: English ซ้าย–ภาษาไทยขวา พร้อมค้นหา กรอง ตรวจสัญลักษณ์ และบันทึกเป็น TSV ปกติ
- ซ่อมคำแปล 145 ข้อความที่เครื่องหมายจัดรูปแบบ `^{…}`, ตัวแปร และวงเล็บชื่อสกิล/เอฟเฟกต์เสียหาย พร้อมเพิ่มตัวตรวจป้องกันการเกิดซ้ำ
- แก้บัคคำว่า `โบนัส` ซ้ำใน Affix โดยคืน `DMG Bonus` และป้ายค่าสเตตัสแบบสั้นเป็นภาษาอังกฤษ
- เพิ่มการจับคู่รายละเอียดสกิล เควส และไอเทมจากตารางจีนให้แสดงข้อความอังกฤษต้นฉบับ โดยไม่แปลคำสั้น ๆ
- จำกัดคำแปลไทยไว้เฉพาะรายละเอียดสกิล/เอฟเฟกต์ รายละเอียดและวัตถุประสงค์เควส และรายละเอียดไอเทม/อาหาร/ยา
- คงชื่อแผนที่ มอนสเตอร์ NPC สัตว์เลี้ยง ไอเทม สกิล เมนู UI และค่าสถานะเป็นภาษาอังกฤษ
- ปิด global priority/regex rules เพื่อลดการแปลเกินขอบเขตและลดอาการหน่วงตอนเปิด UI
- เปลี่ยนตัวติดตั้ง ตัวอัปเดต ตัวถอนการติดตั้ง และแพ็กเกจ Release เป็นชื่อภาษาไทย
- รองรับการอัปเดตออนไลน์จาก `glitzhXEC/RO3_Asia_Thai_Patch` และโหมด `--local`
- ยังคงกลไกสำรอง/กู้คืนและการตรวจ SHA-256 จากโครงการต้นฉบับ

## หมายเหตุ

คำแปลรุ่นแรกยังต้องตรวจแก้คำศัพท์และบริบทในเกม โดยเฉพาะชื่อสกิล ไอเทม มอนสเตอร์ แผนที่ และข้อความที่มีตัวแปร
