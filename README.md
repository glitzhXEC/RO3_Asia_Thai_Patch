# RO3 Asia แพตช์ภาษาไทย

แพตช์นี้ช่วยแปล **รายละเอียดสกิล เควส และไอเทม** ของ RO3 Asia เวอร์ชัน PC ให้เป็นภาษาไทย ส่วนเมนู ชื่อ NPC มอนสเตอร์ ไอเทม สกิล และค่าสถานะจะคงเป็นภาษาอังกฤษ

## ดาวน์โหลด

ดาวน์โหลดไฟล์ ZIP รุ่นล่าสุดจาก [หน้า Releases](https://github.com/glitzhXEC/RO3_Asia_Thai_Patch/releases/latest) แล้วแตกไฟล์ ZIP ก่อนติดตั้ง ไม่ต้องดาวน์โหลด Source code

## ติดตั้งแบบง่าย

1. ปิดเกม RO3 และ RO3AsiaLauncher
2. เปิดโฟลเดอร์ที่แตกไฟล์ ZIP ไว้
3. ดับเบิลคลิก `Install-Thai.bat`
4. เมื่อโปรแกรมถาม ให้เลือกโฟลเดอร์ `Client` ที่มีไฟล์ `ro3.exe`
5. รอจนเห็นข้อความ `[OK] Thai patch installed` แล้วเปิดเกมผ่าน RO3AsiaLauncher

อีกวิธีหนึ่งคือลากไฟล์ `ro3.exe` หรือโฟลเดอร์ `Client` ไปวางบน `Install-Thai.bat`

## ใช้ CMD

เปิด CMD แล้วเปลี่ยนไปยังโฟลเดอร์ที่แตกไฟล์แพตช์ไว้ จากนั้นสั่งติดตั้ง โดยเปลี่ยนตัวอย่างทั้งสองตำแหน่งให้ตรงกับเครื่องของคุณ:

```bat
cd /d "C:\Users\ชื่อผู้ใช้\Downloads\RO3_Asia_Thai_Patch"
Install-Thai.bat "C:\Games\RO3\Client"
```

`C:\Games\RO3\Client` ต้องเป็นโฟลเดอร์ที่มี `ro3.exe` อยู่ข้างใน

## ใช้ PowerShell

เปิด PowerShell แล้วเปลี่ยนไปยังโฟลเดอร์ที่แตกไฟล์แพตช์ไว้ จากนั้นสั่งติดตั้ง:

```powershell
Set-Location "C:\Users\ชื่อผู้ใช้\Downloads\RO3_Asia_Thai_Patch"
.\Install-Thai.bat "C:\Games\RO3\Client"
```

แก้ตัวอย่าง `C:\Users\ชื่อผู้ใช้\Downloads\RO3_Asia_Thai_Patch` และ `C:\Games\RO3\Client` ให้เป็นตำแหน่งจริงในเครื่อง

## อัปเดตแพตช์

ปิดเกมและ Launcher ก่อน แล้วเปิด `Update-Thai.bat` โปรแกรมจะตรวจและดาวน์โหลดรุ่นล่าสุดให้อัตโนมัติ ถ้าต้องการระบุโฟลเดอร์เกมใน CMD หรือ PowerShell ให้ใช้คำสั่ง:

```bat
Update-Thai.bat "C:\Games\RO3\Client"
```

ถ้าต้องการติดตั้งจากไฟล์แพตช์ที่แตกไว้อยู่แล้ว โดยไม่ดาวน์โหลดจากอินเทอร์เน็ต ให้ใช้:

```bat
Update-Thai.bat --local "C:\Games\RO3\Client"
```

## ถ้าคำแปลยังไม่ขึ้น

ปิดทั้งเกมและ RO3AsiaLauncher แล้วเปิด `Install-Thai.bat` อีกครั้ง โดยเลือกโฟลเดอร์ `Client` ที่มี `ro3.exe` จากนั้นเปิดเกมผ่าน Launcher หากยังพบปัญหา ให้แนบภาพหน้าจอและข้อความที่แสดง

## กู้คืนหลังเกมซ่อมไฟล์

ถ้าใช้คำสั่ง Repair ของเกมแล้วคำแปลหาย ให้เปิด `Recover-Thai.bat` หลังปิดเกมและ Launcher หากเพิ่งใช้ Repair อย่างเป็นทางการ ให้ใช้ `Recover-After-Official-Repair.bat` เฉพาะเมื่อการซ่อมเสร็จสมบูรณ์และเปิดเกมได้แล้ว โปรแกรมจะขอให้พิมพ์ `REPAIRED` เพื่อยืนยันก่อนกู้คืน

## ถอนการติดตั้ง

ปิดเกมและ Launcher แล้วเปิด `Uninstall-Thai.bat` จากนั้นเลือกโฟลเดอร์ `Client` หากเครื่องมี BepInEx อยู่ก่อนติดตั้งแพตช์ ตัวถอนติดตั้งจะหยุดไว้เพื่อป้องกันการลบ BepInEx ที่โปรแกรมหรือม็อดอื่นใช้อยู่

## ข้อควรทราบ

- แพตช์นี้เป็นผลงานชุมชน ไม่ใช่แพตช์ทางการของเกม
- คำแปลบางส่วนอาจยังไม่สมบูรณ์ ชื่อเฉพาะและค่าสถานะบางคำตั้งใจคงเป็นภาษาอังกฤษ
- ความเข้ากันได้กับเกมรุ่นใหม่ ระบบป้องกันโกง และข้อกำหนดของเกมอาจเปลี่ยนแปลงได้

## เครื่องมือช่วยแปล TSV

ในโฟลเดอร์ `Translation-Editor` มีเครื่องมือแปลแบบออฟไลน์สำหรับผู้ที่ต้องการแปลด้วยมือ ดับเบิลคลิก `Open-Translation-Editor.bat` แล้วเปิดไฟล์ `.tsv` ได้ทันที ภาษาอังกฤษจะแสดงด้านซ้ายและภาษาไทยด้านขวา

เครื่องมือรองรับการค้นหา กรองรายการที่ยังไม่แปล ตรวจ `${…}`, `@{…}`, `^{…}` และชื่อในวงเล็บแบบสด รวมถึงบันทึกกลับเป็นไฟล์ TSV ปกติ โดยไม่มีการอัปโหลดข้อมูลออกจากเครื่อง

## สำหรับผู้ร่วมแปล

ไฟล์คำแปลอยู่ใน `_TranslationWorkspace/split_1000` หากแก้คำแปล ให้คงตัวแปร เช่น `${1}` และ `@{1}` รวมถึงแท็กของเกมไว้ แล้วตรวจด้วยคำสั่ง:

```bat
py -3 scripts\validate-thai-payload.py
```
