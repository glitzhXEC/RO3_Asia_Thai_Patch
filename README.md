# RO3 Asia แพตช์ภาษาไทย

แพตช์คำอธิบายภาษาไทยแบบไม่เป็นทางการสำหรับ RO3 Asia เวอร์ชัน PC พัฒนาต่อยอดจากโครงสร้างของ RO3 Asia Japanese Patch

> [!WARNING]
> คำแปลรุ่นแรกสร้างด้วยระบบแปลอัตโนมัติครบทั้งชุด จึงอาจมีคำศัพท์ ชื่อไอเทม ชื่อสกิล และประโยคบางส่วนที่ยังไม่เป็นธรรมชาติ โปรดรายงานข้อความที่ควรแก้พร้อมภาพหน้าจอและบริบท

## ขอบเขตคำแปล

แพตช์เน้นให้ตัวเกมและ UI เป็นภาษาอังกฤษ และแปลไทยเฉพาะ:

- รายละเอียดสกิลและเอฟเฟกต์สกิล
- รายละเอียดและวัตถุประสงค์เควส
- รายละเอียดไอเทม อาหาร และยา

ชื่อแผนที่ มอนสเตอร์ NPC สัตว์เลี้ยง ไอเทม สกิล เมนู และข้อความ UI อื่นจะคงเป็นภาษาอังกฤษ รวมถึงค่าสถานะ `STR`, `AGI`, `VIT`, `INT`, `DEX` และ `LUK`

## ดาวน์โหลด

ดาวน์โหลดรุ่นล่าสุดจาก [GitHub Releases](https://github.com/glitzhXEC/RO3_Asia_Thai_Patch/releases/latest) ผู้ใช้งานทั่วไปไม่จำเป็นต้อง Clone รีโพนี้

## ติดตั้ง

1. ปิด RO3 และ RO3AsiaLauncher
2. แตกไฟล์ `RO3_Asia_Thai_Patch_*.zip`
3. เปิด `Install-Thai.bat`
4. เลือกโฟลเดอร์ `Client` ที่มี `ro3.exe` หรือวาง `ro3.exe`/โฟลเดอร์ `Client` ลงบนไฟล์ BAT
5. เมื่อเห็น `[OK] Thai patch installed` ให้เปิดเกม

หากติดตั้งครั้งแรกแล้วคำแปลยังไม่ขึ้น ให้ปิดเกม รัน `Install-Thai.bat` อีกครั้ง แล้วเปิดเกมใหม่

## อัปเดต

ปิดเกมแล้วเปิด `Update-Thai.bat` ตัวอัปเดตจะตรวจ GitHub Releases และตรวจ SHA-256 เมื่อมีไฟล์กำกับ

โหมดออฟไลน์:

```bat
Update-Thai.bat --local "C:\Games\RO3\Client"
```

## ถอนการติดตั้ง

ปิดเกมแล้วเปิด `Uninstall-Thai.bat` จากนั้นเลือกโฟลเดอร์ `Client` ระบบจะไม่ลบ BepInEx ที่มีอยู่ก่อนติดตั้งแพตช์นี้

## สำหรับผู้ร่วมแปล

- ต้นฉบับหลักอยู่ใน `_TranslationWorkspace/split_1000`
- รักษาตัวแปร เช่น `${1}`, `@{1}`, แท็กสี และลิงก์ของเกมให้ครบ
- แก้ไฟล์แบ่งงานใน `_TranslationWorkspace/split_1000` และอัปเดต payload ที่ตรงกันใน `Client`
- รัน `python scripts/validate-thai-payload.py` ก่อน commit
- ควรตรวจคำศัพท์ซ้ำในหลายบริบทก่อนแก้แบบแทนที่ทั้งระบบ

## ข้อควรทราบ

- แพตช์นี้เป็นผลงานชุมชนและไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการ
- ไม่มีการรับประกันความเข้ากันได้กับอัปเดตเกม ระบบป้องกันโกง หรือข้อกำหนดการให้บริการ
- หากเกมอัปเดตแล้วเกิดปัญหา ให้หยุดใช้งานแพตช์และตรวจรุ่นล่าสุดก่อน
