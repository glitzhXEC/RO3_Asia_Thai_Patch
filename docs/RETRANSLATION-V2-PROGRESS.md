# Thai Retranslation V2

คำแปล V2 เป็นการเขียนรายละเอียดใหม่จากต้นฉบับอังกฤษ ไม่ใช่การแก้คำผิดบน
คำแปลอัตโนมัติเดิม งานแบ่งเป็นชุดเล็กเพื่อให้ตรวจศัพท์ ตัวแปร และภาพในเกมได้
ก่อนนำไปใช้กับชุดถัดไป

## ขอบเขตที่ตรวจพบ

- ข้อความไม่ซ้ำใน namespace ที่อนุญาต: **4,278 รายการ**
- ตัวอักษรต้นฉบับรวม: **432,623 ตัวอักษร**
- ไฟล์ workspace: **27 ไฟล์**
