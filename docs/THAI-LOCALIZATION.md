# สถาปัตยกรรมคำแปลภาษาไทย

## เหตุผลที่ path ภายในยังเป็น `Translation/ja`

Release ภาษาไทยรุ่นแรกใช้ DLL ที่ผ่านการทดสอบจากโครงการต้นฉบับ ซึ่งอ่านพจนานุกรมจาก `BepInEx/Translation/ja/Text` แบบตายตัว ดังนั้น `ja` ใน path และ `Language=ja` เป็นเพียงรหัสภายในเพื่อความเข้ากันได้ ส่วนข้อความปลายทางทั้งหมดเป็นภาษาไทย

การเปลี่ยนรหัสภายในเป็น `th` ต้อง rebuild `RO3.LocalizationTablePatcher.dll` กับ assembly ของเกมและทดสอบ fallback font ในเกมจริง จึงควรทำเป็นงานแยกหลังจากรุ่นภาษาไทยพื้นฐานใช้งานได้แล้ว

## แหล่งข้อมูล

- ข้อความหลัก: `_TranslationWorkspace/split_1000`
- พจนานุกรมที่ Release ใช้จริง: `Client/BepInEx/Translation/ja/Text`
- ตาราง ID และ alias: `Client/BepInEx/config/RO3.LocalizationOverrides.tsv` และ `RO3.LocalizationAliases.tsv`

## กติกาการแก้คำแปล

1. ห้ามลบหรือแปลตัวแปร `${1}`, `@{1}`, `$1` และตัวแปรลำดับอื่น
2. รักษาแท็ก `<color>`, `<link>` และ escape ของ XUnity
3. ตรวจชื่อเดียวกันในบริบทสกิล บัฟ ไอเทม และ UI ก่อนแทนที่ทั้งระบบ
4. รัน `python scripts/validate-thai-payload.py` ก่อน commit
5. ทดสอบในเกมจริง โดยเฉพาะสระ/วรรณยุกต์ไทยและข้อความ TextMeshPro

## สถานะคุณภาพ

ชุดเริ่มต้นแปลอัตโนมัติครบทุกแถวเพื่อให้ทดสอบ coverage ได้เร็ว ยังไม่ถือว่าเป็นคำแปลไทยฉบับตรวจทาน การแก้คำศัพท์โดยชุมชนควรส่งเป็น commit ขนาดเล็กพร้อมภาพหน้าจอหรือบริบทในเกม
