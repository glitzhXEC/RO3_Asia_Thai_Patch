RO3 Translation Editor
======================

1. ดับเบิลคลิก Open-Translation-Editor.bat
2. กด "เปิดไฟล์ TSV" หรือวางไฟล์ .tsv ลงในหน้าต่าง
3. แปลภาษาอังกฤษด้านซ้ายเป็นภาษาไทยด้านขวา
4. แก้รายการที่ระบบแจ้งว่าสัญลักษณ์ไม่ครบ
5. กด "บันทึก" เพื่อบันทึกกลับเป็นไฟล์ TSV ปกติ

คีย์ลัด:
- Ctrl+O เปิดไฟล์
- Ctrl+S บันทึก
- Alt+ลูกศรขึ้น/ลง เปลี่ยนรายการ

เครื่องมือทำงานในเครื่องทั้งหมดและไม่อัปโหลดไฟล์ไปที่ใด
